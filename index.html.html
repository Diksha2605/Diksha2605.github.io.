Label Quality & Noise Engine

  • Python
  • Scikit-learn
  • Random Forest

Mislabelled rows quietly cap what a model can learn.

Method

Ensemble disagreement scoring flags mislabelled samples in a 41,188-row financial dataset. Where the ensemble members disagree with a row's label, the row is suspect.

Feature Importance Instability Detector

  • Python
  • SHAP
  • NumPy

If a feature's rank keeps changing, the explanation can't be relied on.

Method

A 100-iteration bootstrap compares SHAP and permutation-based feature-rank variance to find the unstable features that drive model degradation.

Use

The findings feed more robust feature-selection decisions. The work also defines an Explanation Stability Index (ESI), built on Kendall's W.
